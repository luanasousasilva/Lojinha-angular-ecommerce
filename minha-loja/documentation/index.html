🛒 Lojinha Angular - E-commerce

Projeto de uma aplicação de e-commerce desenvolvida com Angular, com foco em boas práticas de desenvolvimento Front-End, organização de código e arquitetura baseada em componentes.

O objetivo do projeto é simular o fluxo básico de uma loja virtual, incluindo listagem de produtos, carrinho de compras e gerenciamento de estado da aplicação.

🚀 Tecnologias utilizadas

  • Angular
  • TypeScript
  • RxJS
  • NgRx (gerenciamento de estado)
  • HTML5
  • CSS3
  • Node.js
  • NPM

📂 Estrutura do projeto

Example :
src/
 ├── app/
 │   ├── components
 │   ├── pages
 │   ├── services
 │   └── store
 ├── assets
 └── environments

A aplicação segue uma arquitetura baseada em componentes reutilizáveis, separação de responsabilidades e organização modular.

⚙️ Como executar o projeto

1. Clonar o repositório

Example :
git clone https://github.com/seu-usuario/lojinha-angular-ecommerce.git

2. Acessar a pasta do projeto

Example :
cd lojinha-angular-ecommerce/minha-loja

3. Instalar dependências

Example :
npm install

4. Rodar o projeto

Example :
ng serve ou npm start

A aplicação estará disponível em:

Example :
http://localhost:4200

📄 Documentação da aplicação

A documentação técnica do projeto é gerada automaticamente utilizando o Compodoc.

Gerar a documentação

Example :
npx compodoc -p tsconfig.app.json

Rodar a documentação no navegador

Example :
npx compodoc -p tsconfig.app.json -s

A documentação estará disponível em:

Example :
http://localhost:8080

O que a documentação inclui

  • Componentes da aplicação
  • Serviços (services)
  • Módulos
  • Estrutura de rotas
  • Dependências entre arquivos
  • Diagrama da arquitetura

✨ Funcionalidades

  • Listagem de produtos
  • Adição de produtos ao carrinho
  • Gerenciamento de estado com NgRx
  • Estrutura modular com Angular
  • Simulação de fluxo de compra

📚 Objetivo do projeto

Este projeto foi desenvolvido com foco em aprendizado e prática de conceitos importantes do desenvolvimento Front-End moderno, incluindo:

  • Arquitetura Angular
  • Gerenciamento de estado
  • Organização de projetos escaláveis
  • Boas práticas de desenvolvimento
